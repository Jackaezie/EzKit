Extremely simple kitPvP data pack for my own personal use. Figured I would make it public if anyone may want to use it for themself.

Use instructions:
place kit items into a single chest hidden anywhere in your world.
top row is for hotbar items.
Last 5 slots are for helmet, chestplate, leggings, boots, and offhand in that order.
in a command block, paste the command:
/function ezkit:kit {coords:"[x1] [y1] [z1]",tpto:"[x2] [y2] [z2]"}
where x1 y1 and z1 are replaced with the coordinates of the chest and x2 y2 and z2 are replace with the coordinates to which the player will be teleported after selecting the kit.
The datapack will automatically target the nearest player, so create a button or a pressure plate through which players will trigger the command block.
